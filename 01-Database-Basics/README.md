\# Database Basics



\## Apa itu Database?



Database adalah kumpulan data yang saling berhubungan dan disimpan secara terstruktur sehingga mudah diakses, dikelola, dan diperbarui.



\## Analogi Database



Bayangkan sebuah perpustakaan.



\- Perpustakaan = Database

\- Rak buku = Tabel

\- Buku = Data (Record)



Semua data berada dalam satu tempat yang terorganisir sehingga mudah dicari.



\## Struktur Database



Database

└── Schema

&#x20;   ├── Table Books

&#x20;   ├── Table Members

&#x20;   ├── Table Borrowers

&#x20;   └── Table Transactions



\## Contoh Database

\## Hal yang Saya Pelajari

\- Sebuah database dapat memiliki banyak tabel.
